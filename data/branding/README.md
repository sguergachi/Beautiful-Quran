# Quran Foundation wordmarks

These are Quran Foundation's official wordmarks, downloaded unchanged on
2026-10-14 from its [website](https://quran.foundation/):

- [Dark ink](https://quran.foundation/_next/static/media/logo.dc586cdd.svg)
- [White ink](https://quran.foundation/_next/static/media/logo-white.ef0c57f2.svg)

Quran Foundation owns these brand assets. They identify the provider on the
account sheet and sign-in action; Beautiful Quran is an independent app.
Keep their colors, aspect ratios and path geometry. Android's matching vector
drawables preserve every SVG path, fill and viewport, with no runtime SVG library.
